## ☁️ Laboratório AWS — Hospedagem de site estático com Amazon S3

### Objetivo

Explorar o armazenamento de objetos na AWS e a estrutura necessária para disponibilizar os arquivos de um site estático.

### O que foi realizado

- Identificação e utilização de um bucket do Amazon S3.
- Trabalho com o bucket `hsm-website-28692320`, na região `us-east-1` (Norte da Virgínia).
- Organização e identificação dos arquivos do site no armazenamento:
  - `index.html` — página principal.
  - `error.html` — página de erro personalizada.
  - `paulo-henrique.png` — imagem utilizada no site.
- Prática com arquivos HTML e recursos estáticos armazenados em um serviço de cloud.
- Familiarização com a estrutura de armazenamento de objetos e os componentes de um site estático.

### Tecnologias

`AWS` `Amazon S3` `Cloud Computing` `HTML` `Static Website Hosting`

**Aprendizado:** contato prático com armazenamento de objetos na AWS, organização de arquivos para um site estático e conceitos de publicação de conteúdo web.

> Este laboratório foi realizado em ambiente de estudo. A disponibilidade posterior do bucket e a publicação contínua do site não foram confirmadas.
